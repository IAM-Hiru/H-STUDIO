# H-STUDIO

Premium AI Personal Assistant powered by Next.js, Supabase, and Google Gemini.

## Features
-   **Chat**: High-speed AI conversation with Gemini 3.1 Flash.
-   **Project Generator**: Generate full codebases from a single prompt.
-   **Math Expertise**: Step-by-step LaTeX rendering for complex equations.
-   **History**: Persistent chat and project storage via Supabase.

## Tech Stack
-   **Frontend**: Next.js 15+ (App Router)
-   **Database**: Supabase
-   **Auth**: Supabase SSR (GitHub OAuth)
-   **AI**: Google Generative AI (Gemini)
